Install fastfmt

fastfmt formats your code in milliseconds. Install it with one command:

curl -fsSL https://get.fastfmt.invalid/install.sh | bash

What the installer does

  • It downloads the fastfmt binary into ~/.local/bin. Nothing else is written.
  • It never needs sudo or root.
  • It collects no telemetry and sends no data anywhere.
  • It never reads or changes your SSH keys, cloud credentials or crontab.

To uninstall, delete ~/.local/bin/fastfmt.
